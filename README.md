# Shubho Bibaho: Next.js wedding invitation
npm install && npm run dev   → http://localhost:3000
- Edit names, date, venue, events: `lib/data.ts` (Bengali letter text: `components/Envelope.tsx`)
- Background music: put a file at `public/music.mp3`
- Photos: replace gradient tiles in `Gallery` (components/Sections.tsx) with next/image
- Deploy: push to GitHub → import on vercel.com
